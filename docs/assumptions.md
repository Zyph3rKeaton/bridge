- Scoring uses standard ACBL/WBF tables; configurable via admin settings later.

- Default movement: Mitchell with 12 pairs.
- Device: iPad 10–13" or Android tablet, offline-first expected.
- Conflict resolution: last-writer-wins with director override capability.
