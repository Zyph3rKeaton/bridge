# Accessibility QA Checklist

- Color contrast ≥ 4.5:1 for body text; ≥ 3:1 for large text.
- Touch targets ≥ 48px; spacing on 8pt grid.
- Focus visible on all interactive elements; focus trap in modals.
- ARIA labels for suit buttons and numeric keypad.
- Skip link present and functional.
- Keyboard navigation supports all actions.
- Reduced motion mode respected.
- Screen reader announcements for toasts and score results.
- Language attributes set and page titles unique.
